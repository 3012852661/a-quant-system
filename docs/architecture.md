# 最终系统架构

目标不是一个单脚本选股器，而是一个多 Agent 量化研究和交易系统。

```text
Codex
├── 数据Agent
├── 新闻Agent
├── 技术分析Agent
├── 基本面Agent
├── 风控Agent
└── 交易Agent

↓

回测

↓

实盘
```

## 核心原则

- 只使用真实数据。
- 数据缺失时返回 `NO_DATA` 或 `BLOCK`，不能编造结论。
- 研究阶段不允许实盘下单。
- 实盘前必须先有足够样本回测。
- 每日股票池、报告、回测结果都要留痕。

## Agent 职责

### 数据Agent

负责获取、校验和标准化真实行情数据。

当前数据源：

- `akshare.stock_zh_a_spot_em`
- `akshare.stock_zh_a_hist`
- `eastmoney.curl.clist`，用于 Python requests DNS 异常时的真实行情备用通道

失败策略：

- 默认失败退出。
- 不自动使用本地文件 fallback。
- 不写入正式 SQLite。

### 新闻Agent

负责读取真实新闻、公告和舆情。

当前状态：

- 未接入真实新闻源。
- 输出 `NO_DATA`。
- 不参与正式买卖决策。

### 技术分析Agent

负责趋势、量价、换手率、量比、技术评分。

当前实现：

```python
score = pct_chg * 2 + volume_ratio * 5 + turnover * 0.5
```

### 基本面Agent

负责估值、财务质量、成长性、行业地位。

当前状态：

- 未接入真实财务数据。
- 输出 `NO_DATA`。

### 风控Agent

负责追高、拥挤、仓位、止损、单票风险、组合风险。

当前实现：

- 接近涨幅上沿给出警告。
- 换手率过高给出警告。
- 量比过高给出警告。

### 交易Agent

负责交易接口和订单执行。

当前状态：

- 默认研究模式。
- 禁止实盘下单。
- 未配置券商接口时返回 `BLOCK`。

## 路线图

### 第一阶段：每日真实股票池

- AkShare 实时行情
- SQLite 落库
- Markdown 日报
- CSV 快照
- 失败不造数据

### 第二阶段：历史回测

- 读取每日股票池
- 第二天开盘买入
- 持有 3 天
- 第 3 天收盘卖出
- 统计收益率、胜率、最大回撤

### 第三阶段：多 Agent 评分

- 新闻源接入
- 基本面数据接入
- 技术 + 新闻 + 基本面 + 风控综合评分

### 第四阶段：模拟盘

- 每日生成交易计划
- 记录计划执行结果
- 验证滑点和成交假设

### 第五阶段：实盘

- 接 QMT / PTrade
- 小资金白名单
- 强制风控
- 人工确认后再逐步自动化
