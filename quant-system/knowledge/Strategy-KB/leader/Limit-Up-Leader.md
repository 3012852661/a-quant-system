# 龙头 / 连板策略

status: L2 normalized
market: A 股短线
horizon: 1-3 个交易日
source: JoinQuant 社区、雪球短线复盘、掘金量化策略样例

## 逻辑

龙头策略寻找市场短线情绪中最强的题材载体。核心不是“涨停”本身，而是题材强度、封单质量、换手承接、连板梯队和市场风险偏好共同确认。

## 信号

- 入场候选：首板或二板后仍有板块扩散，成交额和换手足够，非一字无量。
- 强确认：同题材出现多只涨停，龙一具备更高封单、换手和辨识度。
- 禁止：高位缩量一字、天地板风险、监管关注、减持/解禁/业绩雷。

## 数据需求

- 实时涨跌幅、成交额、换手率、封单、开板次数。
- 同题材涨停数量、强势未封数量、昨日龙头延续状态。
- 新闻、公告、政策和社交热度只作辅助，不作单独触发。

## 风控

- 只允许小仓试错，首笔不超过权益的 5%-8%。
- 失败必须次日纪律退出，不能补仓摊平。
- 市场退潮期只观察，不做自动交易。

## Agent 使用

该策略只允许在人工确认或模拟交易中使用。自动交易必须额外满足：数据审计 OK、报价新鲜、投委会置信度达标、无监管/公告硬风险。
