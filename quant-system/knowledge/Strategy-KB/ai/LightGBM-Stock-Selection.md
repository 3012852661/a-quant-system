# LightGBM 选股策略

status: L2 normalized
market: A 股
horizon: 1-20 个交易日
source: BigQuant、Qlib、机器学习选股常见框架

## 逻辑

LightGBM 用树模型学习非线性因子组合，适合处理价格、量能、资金流、估值和行业特征。它不是自动交易策略本身，只是候选排序器。

## 数据

- 日频行情、复权价、成交额、换手率。
- 基本面和估值因子。
- 行业、市值、停牌、ST、涨跌停状态。
- 严格时间切分，防止未来函数。

## 入场

- 模型预测收益进入 Top 分位。
- 标的通过流动性、风控、数据审计过滤。
- 技术面未出现冲高回落、跌破止损等否决项。

## 退出

- 持有期到期。
- 预测分位跌出阈值。
- 触发止损、风险官否决或市场状态降级。

## 风控

- 必须记录训练集、验证集、测试集时间。
- 每次模型升级必须重新回测。
- 自动交易只能使用 L4 版本模型，不允许直接引用未验证 notebook。

## Agent 使用

Agent 可以把该策略作为排序参考，但下单前必须结合 Strategy-KB、Risk-KB、投委会和组合仓位闸门。
