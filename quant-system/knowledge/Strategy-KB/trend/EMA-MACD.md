# EMA / MACD 趋势策略

status: L2 normalized
market: A 股、ETF、指数
horizon: 3-20 个交易日
source: TA-Lib, TradingView, Backtrader 常见策略

## 逻辑

EMA 用指数加权均线识别趋势方向，MACD 用快慢 EMA 差值识别动量变化。它适合趋势延续行情，不适合横盘震荡和消息驱动的快速反转。

## 信号

- 入场：短 EMA 上穿长 EMA，MACD DIF 上穿 DEA，成交额高于近 20 日均值。
- 加分：股价站上 20 日线，行业指数同步走强，主力净流入为正。
- 退出：短 EMA 下穿长 EMA，或 MACD 死叉，或跌破 ATR 止损线。

## A 股适配

- 涨停附近不追价，优先等待次日回踩或集合竞价确认。
- 一字板、停牌、新股、ST、成交额不足标的必须过滤。
- 回测必须加入 T+1、手续费、印花税和滑点。

## 风控

- 单票仓位不超过组合权益的 8%-12%。
- 若指数处于弱势，信号只进入 WATCH，不进入 TRADE。
- 连续 3 笔亏损后暂停该策略，进入复盘。

## Agent 使用

AI Agent 可以把该策略作为趋势确认模块，但不能单独作为买入依据。必须同时通过数据审计、资金流、回测样本和组合风控。
