# News-KB

status: L1 note
market: A 股
source: 人工新闻入库、政策新闻、行业快讯、公司新闻

## 入库字段

- 标题、来源、发布日期、原文链接。
- 关联股票代码、行业、主题。
- 事实摘要，只记录新闻事实，不写交易结论。
- 影响路径，说明订单、毛利率、估值、资金情绪或监管风险可能如何传导。
- 风险和不确定性，标记消息真实性、落地周期、兑现压力和反向风险。

## Agent 使用

- 新闻 Evidence 只能作为研究层和舆情层证据。
- 新闻不允许单独触发自动买入。
- 与公告、财务、研报冲突时，优先级低于公司公告和结构化财务数据。
- 超过 30 天的新闻默认视为历史背景，除非它仍在政策执行期或事件跟踪期。
