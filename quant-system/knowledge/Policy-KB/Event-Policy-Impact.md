# 政策事件影响路径

status: L1 note
market: A 股
source: 政策新闻、监管公告、行业政策解读

## 框架

政策影响不直接等于买入信号，需要拆成四层：

1. 政策方向：支持、限制、监管、补贴、准入。
2. 产业链位置：上游、中游、下游、设备、材料、渠道。
3. 财务传导：订单、毛利率、资本开支、估值重定价。
4. 市场交易：题材热度、资金拥挤、兑现风险。

## 风控

- 只看标题容易误判，必须检查受益主体和落地周期。
- 高开过多时，政策利好容易变成兑现压力。
- 监管处罚、减持、业绩雷优先级高于题材热度。

## Agent 使用

政策条目只作为投委会证据来源，不允许单独触发自动买入。
