# Alpha158 因子组

status: L1 note
market: A 股、可扩展到多市场
source: Microsoft Qlib

## 说明

Alpha158 是 Qlib 中常用的工程化因子集合，覆盖价格、成交量、滚动窗口统计、均线偏离、波动率等特征。它适合做机器学习选股的基础特征层。

## 入库要点

- 明确每个因子的计算窗口和复权口径。
- 区分日频、分钟频和盘后可得数据，避免未来函数。
- 训练/验证/测试必须按时间切分，不能随机切分。
- 需要行业中性化、市值中性化和缺失值处理方案。

## Agent 使用

Agent 只能引用 Alpha158 作为“因子特征来源”，不能把它描述成完整交易策略。进入交易计划前必须经过模型训练、回测和风控。
