# 研报标题

status: L1 note
market: A 股
source: 机构名称
institution: 机构名称
author: 作者/分析师
published_at: YYYY-MM-DD
url: 原文链接或 PDF 路径
symbols: 000001, 600000
rating: 买入/增持/中性
target_price: 目标价或估值区间

## 核心观点

- 记录事实、预测和作者判断，三者不要混在一起。

## 财务假设

- 收入、利润、毛利率、现金流、估值假设必须标注年份和口径。

## 催化因素

- 订单、政策、产品、产能、价格、份额等催化。

## 风险提示

- 风险提示必须完整入库，不能只摘利好。

## Agent 使用

- 研报 Evidence 必须说明来源和日期；过期研报只能作为历史观点。
