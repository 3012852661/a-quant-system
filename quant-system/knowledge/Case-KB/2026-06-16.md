# 2026-06-16 系统优化案例

status: L1 note
type: system-improvement

## 背景

系统已经具备行情扫描、推荐、投委会、模拟交易和自动交易预检，但策略知识仍分散在代码与临时说明里。

## 本次优化

- 新增六层知识库结构。
- 建立策略条目质量等级。
- 将 Strategy-KB 和 Risk-KB 接入工作台展示。
- 明确自动交易只允许引用高质量、可回测、可风控的知识条目。

## 后续复盘问题

- 哪些策略已经完成 L3 回测？
- 哪些来源的许可证允许代码复用？
- 知识库条目如何进入投委会证据表？
- Case-KB 如何反哺策略禁用条件？
