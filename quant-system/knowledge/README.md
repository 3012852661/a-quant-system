# AI Stock Agent Knowledge Base

这个知识库不是资料收藏夹，而是给 AI+A 股交易系统使用的结构化研究层。所有条目都应该服务于同一条链路：

`检索 -> 证据归因 -> 策略适配 -> 回测验证 -> 风控约束 -> 复盘迭代`

## 知识库结构

| 知识库 | 目标 | 入库重点 |
| --- | --- | --- |
| Strategy-KB | 策略知识 | 选股逻辑、择时逻辑、适用市场、失效场景 |
| Factor-KB | 因子知识 | 因子定义、计算口径、行业中性化、IC/RankIC |
| Policy-KB | 政策知识 | 监管政策、产业政策、交易制度、事件影响路径 |
| Report-KB | 研报知识 | 券商观点、行业框架、财务假设、风险提示 |
| News-KB | 新闻证据 | 公司新闻、行业快讯、人工入库事实、影响路径 |
| Case-KB | 历史案例 | 当日交易计划、盘后复盘、错因归档、样本标签 |
| Risk-KB | 风控知识 | 仓位、止损、回撤、黑名单、数据质量闸门 |

## 来源优先级

| 类型 | 来源 | 用途 | 入库要求 |
| --- | --- | --- | --- |
| 开源策略 | GitHub, Qlib, FinRL, Backtrader, vn.py | 代码和策略原型 | 必须记录许可证、适配成本、回测假设 |
| 学术论文 | arXiv, SSRN | 因子、模型、组合优化 | 必须记录论文结论、样本市场、可复现性 |
| 量化平台 | JoinQuant, BigQuant, RiceQuant | A 股策略样例 | 必须记录参数、手续费、滑点、回测周期 |
| 社区论坛 | 聚宽社区、掘金量化、雪球 | 实盘经验和情绪线索 | 只作假设来源，不直接作买卖依据 |
| 技术指标 | TA-Lib, TradingView | 指标公式和策略脚本 | 必须转换为统一公式和参数说明 |
| AI 策略 | HuggingFace, GitHub Awesome | 模型结构和训练思路 | 必须记录数据泄漏风险和线上推理成本 |
| 书籍 | 经典量化/交易书籍 | 框架和方法论 | 必须转写为可检索 Markdown 摘要 |

## 条目质量等级

- `L0 raw`：只保存原始链接或摘录，不能被交易系统直接引用。
- `L1 note`：有摘要、来源、关键词，可被检索。
- `L2 normalized`：有统一字段、适用场景、风险、参数，可进入策略候选池。
- `L3 tested`：完成本系统数据口径回测，有样本数、收益、回撤、胜率。
- `L4 production-guarded`：完成风控闸门、复盘样本和禁用条件，可进入自动预检。

## 入库字段

每个策略或因子文档建议包含：

- `source`：来源、链接、作者、许可证或引用方式。
- `market`：A 股、ETF、港股、美股、期货等。
- `horizon`：日内、1-3 日、1-4 周、中长期。
- `logic`：信号逻辑和经济含义。
- `data`：所需数据、刷新频率、延迟容忍度。
- `params`：核心参数和默认值。
- `entry`：入场条件。
- `exit`：止盈、止损、时间止损、失效条件。
- `risk`：仓位、回撤、黑天鹅、拥挤交易。
- `backtest`：样本期、交易成本、关键指标。
- `agent_usage`：AI Agent 何时能引用、何时必须拒绝。

## 推荐流程

1. 收集资料只进入 `L0 raw` 或 `L1 note`。
2. 人工或 AI 归一化为策略卡片，升到 `L2 normalized`。
3. 接入本系统回测引擎，生成可比指标，升到 `L3 tested`。
4. 绑定风控规则、数据质量规则、复盘标签，升到 `L4 production-guarded`。
5. 前端和投委会只引用 `L2+`，自动交易只允许引用 `L4`。
